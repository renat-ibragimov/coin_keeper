# 00. Обзор и карта документов

## Что строим

Веб-приложение для учёта коллекции монет: каталог выпусков, личная коллекция, покупки и расходы,
рыночные цены, комплектность по сериям. Заменяет закрытую десктопную версию.

Дальше — мобильные приложения (iOS/Android) поверх того же API.

## Предыстория

С июля по август 2026 существовала десктопная версия: Electron + React + SQLite, позже начата
миграция на Tauri. Она работала и накопила реальные данные, но архив проекта был повреждён при
переносе — часть файлов обнулена побайтово.

**Что утрачено безвозвратно:**

- `src/` — исходники React-интерфейса
- `src-tauri/` — Rust-часть
- `scripts/` — вспомогательные скрипты
- живая база данных (обнулена)
- 842 из 1681 файла фотографий

**Что уцелело и лежит в `legacy/`:**

| Артефакт | Файл |
|---|---|
| Рабочая база на 2026-08-06 | `legacy/data/coinkeeper-2026-08-06.db` |
| Полный DDL этой базы | `legacy/legacy-schema.sql` |
| Исходное ТЗ | `legacy/PRODUCT_VISION.md` |
| Эталонная бизнес-логика | `legacy/reference-code/*.ts` |
| Тексты и навигация интерфейса | `legacy/ui-strings.json` |
| Фотографии | `legacy/data/media/` (839 файлов) |

Восстановление десктопной версии не планируется.

## Ключевые решения (зафиксированы)

| Вопрос | Решение |
|---|---|
| Формат | Веб. Оффлайн-режим и десктоп не поддерживаются |
| Пользователи | Публичный сервис, но на старте — минимум: регистрация по email и паролю |
| Хостинг | Свой сервер Hetzner + домен, Docker Compose |
| Фронтенд | Пишем с нуля, ориентируясь на восстановленную карту экранов |
| Мобильные приложения | После веб-MVP, поверх того же API |

## Что в этих данных

Две независимые сущности, которые нельзя путать:

**Каталог** (3063 позиции) — справочник существующих выпусков монет. Год, номинал, металл,
тираж, каталожные номера. Позиция существует независимо от того, есть ли монета у кого-то.
Источник: выгрузка с uCoin.net (2824) и скрейпинг каталога uCoin.net (239).

**Коллекция** (620 экземпляров) — реальные монеты владельца: Украина 360, США 196, СССР 64.
Потрачено 42 765,66 грн, покупки с 2009 по 2026 год. История покупок пришла из личного
Excel-файла владельца.

Подробности — `docs/09-data-migration.md`.
