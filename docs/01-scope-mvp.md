# 01. Границы MVP

## Принцип отбора

В MVP входит то, что **реально использовалось** в десктопной версии. Проверено по данным
в `legacy/data/coinkeeper-2026-08-06.db`: если таблица пустая после года работы — функция
в MVP не идёт.

Факты из базы:

| Таблица | Записей | Вывод |
|---|---|---|
| `catalog_items` | 3063 | ядро, обязательно |
| `collection_items` | 620 | ядро, обязательно |
| `market_price_snapshots` | 3938 | активно использовалось |
| `expenses` | 620 | все записи — категория `coin_purchase`, автосоздание при покупке |
| `exchange_rates` | 282 | использовалось |
| `media_files` | 5066 | использовалось |
| `coin_series` | 49 | использовалось |
| `ucoin_catalog_sources` | 8 | использовалось |
| `collection_goals` | **0** | не использовалось → откладываем |
| `purchase_offers` | **0** | не использовалось → откладываем |
| `sales` | **0** | не использовалось → откладываем |
| `catalog_variants` | **0** | не использовалось → откладываем |
| `audit_log` | **0** | не использовалось → откладываем |

Дополнительно: поле `grade` (состояние) не заполнено **ни у одной** из 620 монет,
`seller` пуст везде, все покупки в UAH, все `quantity = 1`.

## Входит в MVP

### Аутентификация
- Регистрация по email и паролю, вход, выход, обновление токена
- Смена пароля
- Данные коллекции привязаны к пользователю

### Каталог
- Список с фильтрами: страна, год, номинал, группа (обиходные / памятные / коллекционные),
  металл (драгоценный / не драгоценный), наличие в коллекции
- Поиск по названию, стране, году, каталожному номеру
- Карточка позиции: характеристики, фото аверса и реверса, история цен, экземпляры в коллекции
- Создание, редактирование, удаление позиции вручную
- Постраничная выдача — 3063 записи нельзя отдавать одним куском

### Коллекция
- Добавление экземпляра к позиции каталога: количество, дата, цена, валюта, продавец, заметка
- Редактирование и удаление
- Фильтр «есть в наличии» / «не хватает»

### Серии
- Список серий по странам
- Сводка: всего позиций, собрано, осталось, процент, сумма покупок, оценка по текущим ценам

### Деньги
- Потрачено на монеты, сопутствующие расходы, итого
- Текущая оценка коллекции по последним ценам
- Курсы НБУ: текущие и исторические на дату покупки
- Расходы по категориям (справочник категорий сохраняем целиком, см. `02-data-model.md`)

### Цены
- Ручное обновление цены для позиции
- Массовое обновление по текущему фильтру, с прогрессом и возможностью остановить
- История цен графиком
- **Валидация цены до записи** — см. `05-integrations.md`

### Импорт
- Excel-выгрузка uCoin (`.xlsx`) с предпросмотром, поиском дублей и отчётом
- Импорт монеты с uCoin по URL
- Импорт раздела каталога uCoin по URL

### Фото
- Загрузка своих изображений аверса и реверса
- Автоматические превью
- Замена и удаление

### Дашборд
- Позиции каталога и экземпляры, комплектность, осталось собрать
- Потрачено / оценка / разница
- Курсы USD и EUR с датой
- Недавно добавленное, ближайшие к завершению серии

### Настройки
- Язык интерфейса (русский / английский)
- Источники каталога uCoin
- Экспорт коллекции в Excel

## Откладываем на после MVP

| Функция | Почему |
|---|---|
| Цели коллекционирования (`collection_goals`) | 0 записей за год использования |
| Предложения о покупке (`purchase_offers`) | 0 записей |
| Продажи (`sales`) | 0 записей, но экран в интерфейсе был |
| Разновидности (`catalog_variants`) | 0 записей; режим «разновидности включены» из ТЗ не проверялся на практике |
| Журнал изменений (`audit_log`) | 0 записей |
| Грейдинг (компания, номер, оценка) | поля есть, данных нет |
| Numista API | требует персонального ключа, в legacy так и не заработал |
| Марки и другие предметы | явная заглушка в исходном ТЗ |
| Годовые PDF-отчёты | не критично для веба |
| Мобильные приложения | после веб-MVP |

Схему под отложенное закладываем сразу (таблицы создаём), API и интерфейс — нет.
Так потом не придётся переделывать миграции.

## Явно вне проекта

- Оффлайн-режим и локальная база на устройстве
- Синхронизация с десктопом
- Портативная сборка
- Восстановление старого Electron/Tauri-кода

## Критерий готовности MVP

Пользователь регистрируется, видит каталог из 3063 позиций с фотографиями, отмечает свои монеты,
вносит покупки, видит сколько потратил и сколько стоит коллекция сейчас, обновляет цены
и импортирует выгрузку с uCoin. Всё это — с телефона через браузер.
