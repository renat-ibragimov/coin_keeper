## 1. Что это и где живёт

- **Продукт:** веб-каталог и коллекция монет. Бренд Bakost Numismatics (семья
  Bakost Club), монограмма BN. Интерфейс uk/en, дефолт uk. Владелец коллекции —
  брат Рената (Олександр), 620 экземпляров. Второй админ — Ренат.
- **Репо:** `github.com/renat-ibragimov/coin_keeper` (публичное; переезд в
  `bakost-numismatics` — после MVP). Спеки в `docs/00…12`, бэклог `docs/BACKLOG.md`,
  правила `CLAUDE.md`.
- **Домен:** `https://coins.renat-ibragimov.com` (Cloudflare DNS only). API `/api/v1`,
  Swagger `/api/v1/docs`.
- **Сервер:** Hetzner `2.28.42.171`, Ubuntu 24.04, 2 vCPU / 3.7 ГБ + своп; центральный
  Caddy в docker (`/srv/caddy`, сеть `web`). Стек — `/home/deploy/coinkeeper`
  (postgres 16, redis, minio, api). Статика фронта — `/srv/coinkeeper/frontend`.
- **SSH:** порты 22 и 2222; `root` (общесерверное) и `deploy` (проект). Для долгих
  команд — tmux (сессии рвутся, «Broken pipe»).
- **CI:** пуш в `main` → check (тесты) → build → deploy (GHCR, тег = SHA) →
  deploy-frontend. Секреты в GitHub: `DEPLOY_*`, `SSH_KNOWN_HOSTS`, `SERVER_ENV`
  (весь серверный `.env` — **любая правка .env на сервере обязана дублироваться в
  секрет, иначе деплой её сотрёт**). Миграции применяются при старте контейнера —
  пуш с миграцией меняет боевую базу: дамп до пуша.
- **LLM:** `ANTHROPIC_API_KEY` стоит на сервере и в `SERVER_ENV`; на балансе ~$5
  (часть C съела центы). Единственный шаг с внешним API — `translate-c`.
- **Пароли/секреты:** только в менеджере паролей Рената. Почта в
  `MAIL_BACKEND=console`.

## 2. Архитектурные решения (не пересматривать без причины)

- Три слоя: общий каталог (`created_by IS NULL`, правит admin), личные позиции,
  коллекция. Архивация вместо удаления; серии общие, создаёт admin.
- **Трёхъязычная модель:** `*_original`+`original_lang` (язык эмитента; для Украины
  это uk), `*_uk`, `*_en`; провенанс `*_source: official | llm | manual`. `manual`
  ставится admin-PATCH-ем автоматически и никогда не перетирается конвейером;
  `llm` перезаписывается только самим translate-c.
- **`collection_group` — ЧЕТЫРЕ значения** (не два!): commemorative (1124),
  collector (387 — Excel-эвристика клала туда драгметаллы), circulation (192),
  other (1). Любые выборки писать с учётом всех четырёх.
- **Витринная видимость** (`docs/04-business-rules.md`, §13): запись общего
  каталога видима, если страна активна ИЛИ это личная позиция пользователя ИЛИ у
  пользователя есть её экземпляр; серия видима, если страна активна ИЛИ есть
  экземпляр в серии. Применено единым предикатом `storefront_visible()` в
  каталоге, «Не вистачає», сериях и агрегатах Огляда. Прямая карточка
  `/catalog/:id` доступна всегда. Активна только Украина (`id 2`); СССР (`id 3`)
  и США (`id 1`) выключены UPDATE-ом 2026-09-05 — данные и личные позиции этих
  стран не трогали, только витрину. Часть правила «владеемое неактивной страны
  видно в каталоге» помечена как временная — владелец ещё думает.
- **Фото: `-nobg` — признак обработанности.** Файлы со срезанным фоном живут под
  ключом с суффиксом `-nobg`; оригиналы никогда не перезаписываются (план
  отката). Суффикс виден в URL — фронт может отличать обработанные фото простой
  проверкой строки (задел для UI-логики, сейчас не используется).
- **Е-каталог НБУ моделирует НАБОРЫ, а не их монеты:** «Енеїда» ×9, «Державні
  символи» (канон: «Наш герб / Наш СТЯГ / Наш гімн» — не «прапор»!), «Козацькі
  клейноди» ×4 существуют у банка только карточками наборов (Енеїда 1476/1477,
  символы 1543 (н, 2022) и 1689 (c, 2025), клейноди 1499/1513). Дешёвых юбилейных
  1 грн и мелкого золота 1 грн в е-каталоге нет вовсе. Наши записи — поштучные
  монеты; это правильнее для коллекционера, линковать их «не во что» — норма.
- **Также у НБУ:** «монета» и «монета у сувенірній упаковці» — отдельные карточки
  с отдельными ценами (50 nbu + 42 ua_coins packaged-строк считаются монетами).
  Целевая модель у нас: упаковочная запись = `catalog_variants` к базовой, витрина
  показывает одну карточку с бейджем (см. §4, «Packaging/set-варианты», и
  `docs/BACKLOG.md`).
- **Медиа:** всё в свой MinIO (300/600/1200 WebP), `media_files.storage_key` — своё,
  `external_url` — хотлинк (фронт чужие URL не показывает). Видимость по источнику:
  `PUBLIC_SOURCES = (nbu, manual, ua_coins)`; user_upload/ucoin — только владельцу.
  Фото ua-coins публичны с 2026-09-05 (была регрессия-невидимость ~290 записей).
  Вопрос прав ua-coins (1264 файла) сознательно отложен до открытия регистрации.
- Код английский; промпты и доки русские; UI-строки через i18n.

### Фото-пайплайн (срез фона)

Модуль `app/services/media_background.py` + скрипт
`scripts/remove_photo_backgrounds.py` (runbook — `backend/README.md`). Классика
без ML: сэмпл углов → белый или чёрный однородный фон → flood-fill (у тёмной
ветки жёсткий допуск — зеркальные пруфы) → граница ≥0.75 периметра → одна
компонента → круглость 0.6–0.87 (отсекает блистеры) → срез + растушёвка + трим
по alpha bbox с ~2% отступом. Guard: вход с осмысленной прозрачностью →
`skip:already_transparent`. Срез вшит в ингест
(`process_image(remove_background=True)`) — парсер и будущая ручная заливка
(этап 6) режут автоматически; миграционные пути передают `False`.

Итог прогонов 2026-09-06: **2465 cut** из 2791 (белые 1762 в три захода, тёмные
703), затем **откат 639** тёмных cut-ов по инциденту (см. ниже) — чистыми
обработано ~1826. Хвост: 171 тёмный-впритык-к-краю (дожимается снижением
порога границы тёмной ветки), 102 неоднородных, 45 fragments, 8 odd_shape, 2
белых краевых.

**Инцидент 2026-09-06**: классификатор игнорировал существующий альфа-канал;
тёмная ветка прочитала чёрную матту под прозрачностью НБУ-исходников как фон и
назначила новую альфу, обнажив скрытый мусор. Закрыт: guard
`already_transparent` + режим `--revert-transparent-originals` (639 строк
откачено, 0 сбоев). Урок: перед новым классом обработки медиа выписывать
инварианты входа.

**Известный шум**: `missing original: 320` во всех прогонах отката — это
легаси-США июньской миграции (схема имён без размерных вариантов,

готовый промпт с фолбэком лежит в столе (см. `docs/BACKLOG.md`).

## 6. Рабочий процесс и уроки (пополнено 2026-09-06)

- Ритм: промпт-файл .md → Клод-код (Sonnet для механики; Opus только для проектных
  кусков с миграциями) → пуш → ревью по репе → боевой прогон по runbook,
  **по одному пункту за раз** (правило Рената, работает отлично).
- **Разведка отдельно от кода:** смешанный промпт Sonnet читает как «сделай» и
  жжёт лимит (был инцидент на пол-ляма). RECON-задачи — plan mode
  (`--permission-mode plan`), результат — файл отчёта; протокол этапов лежит
  готовым шаблоном (спрашивает режим перед каждым этапом).
- **Фикстуры парсеров — только с живых страниц** (два бага подряд от выдуманного
  HTML: карта фото-типов и тиражи 1992). Сырой HTML — на диск, не в контекст.
- Всегда `--dry-run` перед `--apply`; дамп перед миграцией и перед большими apply;
  ревью-CSV utf-8-sig; файлы ревью — `/home/deploy/*.csv` + `-v ...:ro`.
- `docker compose run --no-deps` для разовых скриптов (без — ждёт/поднимает
  зависимости); psql с `-P pager=off`; недетерминизм LLM: то, что видел в CSV, и
  то, что записал apply, — два разных вызова, финал проверять SELECT-ом.
- Санити-чек глазами после каждого боевого прогона обязателен: три из четырёх
  реальных багов сегодня нашёл Ренат по витрине, а не отчёты.
- SQL на сервере — только в формате
  `docker compose exec postgres psql -U coinkeeper -d coinkeeper -P pager=off -c "…"`.
- Прогоны скрипта пайплайна: маунт отчётов обязателен
  (`-v /home/deploy/coinkeeper/migration-reports:/app/migration-reports`),
  длинные — из tmux, **один режим за раз**, никогда параллельно.
- scp с сервера: `scp -P 2222` (порт заглавной `P`).
- Во всех промпт-файлах — указание Клод-коду общаться в терминале по-русски
  (код/коммиты английские).
- Самостоятельные коммиты владельца по фронту: после пуша — беглый прогляд
  каталога в обеих темах (самый хрупкий экран: blend, isolation, растянутые
  ссылки); правки CoinImage/CoinCard — на ревью ассистенту. Прод смотреть
  через жёсткий F5 (Ctrl+Shift+R) — уже ловили старый бандл.
- **Blend-цепочка фото:** любые z-index / isolation / opacity / transform /
  filter на предках `<img>` режут `mix-blend-mode`. История: isolation на
  фреймах нахлёста убил растворение белого (регресс пойман на проде).
