system, in English. History lives in git, not here. Rules for agents and contributors:
`../AGENTS.md`.

(`python3 tools/docs_check.py table`). The `commit-msg` hook enforces it — see

## Writing docs

- **Current state only**, in English. No "stage N", "was / now", "decided on <date>" — if
  a decision's reasoning matters, state the reasoning. History is git's job.
- **Cite a document with its path and, when useful, a section heading in quotes:**
  `docs/api.md, "Multi-value filters"`. Business rules are cited by ID:
  `docs/business-rules.md, BR-13a`. Never cite section numbers — they shift.
- **Headings are an interface.** Code cites them, so renaming a heading means updating
  its citations in the same commit; `tools/docs_check.py refs` lists any that broke.
  `BR-N` IDs are never renumbered or reused.
- UI copy lives in `frontend/src/shared/i18n/`, not in docs. Quote a string in a doc only
  when the rule is about that string.
- Never link to `docs/current_ref/` (scratch screenshots for one conversation).

## How docs are kept in step

Three layers, the same for people, Claude Code and Codex:

1. **Before the commit — `commit-msg` hook** (`.githooks/commit-msg`, enabled once per
   clone with `git config core.hooksPath .githooks`). It maps the staged files through
   `doc-map.toml` and blocks the commit with a "DOCS UPDATE REQUIRED" banner if a mapped
   document isn't staged too. If behavior, API, schema, UI and infra are unchanged
   (refactor, tests, formatting), say so with a trailer in the message:
   `Docs: not needed (<why>)`. It also checks references in the staged files and rejects
   Russian in the message.
2. **In CI — `.github/workflows/docs.yml`** runs `python3 tools/docs_check.py refs`
   (every cited doc, section and `BR-N` exists; no Russian outside data files) and
   `table --check` (this README's table matches `doc-map.toml`).
3. **Periodic audit — the `sync-docs` skill** (`.agents/skills/sync-docs/SKILL.md`) walks
   the code changed since each document was last touched and proposes patches for what
   the per-commit discipline missed.
