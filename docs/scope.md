## Входит в MVP

### Аутентификация
- **Открытая регистрация с первого дня** по email и паролю
- Обязательное подтверждение email: аккаунт неактивен до перехода по ссылке
- Восстановление пароля по ссылке из письма
- Вход, выход, обновление токена, смена пароля
- Ограничение частоты запросов и honeypot в форме регистрации
- Данные коллекции привязаны к пользователю
- **Вход через Google (OAuth) и линковка аккаунтов** — реализовано (решение
  владельца 2026-09-15): зарегистрировался по email — можно привязать
  Google-вход на тот же адрес и наоборот; конфликт (email уже привязан к
  другому Google-аккаунту) возвращает `409`
  (`backend/app/api/v1/google_auth.py`, `services/google_auth.py`,
  `frontend/src/features/auth/pages/GoogleSignIn.tsx`,
  `GoogleCompletePage.tsx`)

Подробности — `auth.md`. Отправка почты через внешний SMTP — `infra.md`.

### Каталог
- Список с фильтрами: страна, год, номинал, группа (обиходные / памятные / коллекционные),
  металл (драгоценный / не драгоценный), наличие в коллекции
- Поиск по названию, стране, году, каталожному номеру
- Карточка позиции: характеристики, фото аверса и реверса, история цен, экземпляры в коллекции
- Постраничная выдача — 3063 записи нельзя отдавать одним куском

**Общий каталог доступен пользователю только на чтение.** Его наполняет администратор и
системная задача по каталогу НБУ. Правило из исходного ТЗ — «внешние источники не создают
каталожных записей» — теперь распространяется и на пользователей.

Убрать позицию из общего каталога можно только **архивацией** (админ, с указанием причины):
запись уходит из витрины, поиска и подсчёта комплектности, но экземпляры, покупки, расходы,
фото и история цен владельцев сохраняются полностью. Физическое удаление общей записи —
редкая админская операция «прибраться за опечаткой», только после архивации и только при
полном отсутствии ссылок. Подробности — `business-rules.md`, п. 10.

### Личные позиции каталога
- Создание, редактирование, удаление своей позиции, если нужного выпуска нет в общем каталоге
- Свои фотографии к ней
- Личные позиции участвуют в фильтрах, поиске, сериях, комплектности и статистике владельца
  наравне с общими
- Видны только автору

Это штатный путь, а не запасной: «не нашли монету в каталоге — заведите свою или
импортируйте выгрузку». Модель — `data-model.md`, правила — `business-rules.md`, п. 2.

### Коллекция
- Добавление экземпляра к позиции каталога: количество, дата, цена, валюта, продавец, заметка
- Редактирование и удаление
- Фильтр «есть в наличии» / «не хватает»

### Комплектність (было «Серии», обобщено 2026-09-23)
- Группировка по любому полю каталога — серия, год, номинал, материал, гурт, качество
  чеканки — вместо только серии, плюс отдельный фильтр по ценности металла
- Сводка по группе: всего позиций, собрано, осталось, процент, сумма покупок, оценка по
  текущим ценам
- Экран детали группы с собственными фильтрами (страна, ценность металла, только наличие)

### Деньги
- Потрачено на монеты, сопутствующие расходы, итого
- Текущая оценка коллекции по последним ценам
- Курсы НБУ: текущие и исторические на дату покупки
- Расходы по категориям (справочник категорий сохраняем целиком, см. `data-model.md`)

### Цены
- **Общий каталог: центральное обновление раз в сутки** системной фоновой задачей,
  источник UA-Coins. Пользовательской кнопки «обновить цену» для общих позиций нет
- **Личные позиции: обновление по требованию владельца** — одной монеты или пачкой по своим
  позициям, с прогрессом и возможностью остановить
- История цен графиком
- **Валидация цены до записи** — см. `integrations.md`

Снимки центральной задачи видны всем; снимки от обновления личных позиций по требованию
владельца видны и учитываются в оценке только у автора (`business-rules.md`, п. 7). Модель
поддерживает тем же полем `created_by` и ручной ввод цены, и снимки из Excel-импорта — обе
функции перенесены после MVP решением владельца 2026-09-15 (см. «Откладываем»), переделывать
схему под них при реализации не придётся.

**Честная граница покрытия:** автоматические цены в MVP покрывают только **украинскую** часть
каталога — UA-Coins других стран не даёт. Цены по США и СССР — то, что перенеслось при
миграции легаси-Excel в этапе 2 (`09-data-migration.md`); довыгрузить их импортом uCoin или
поправить вручную в MVP нельзя, обе функции — после MVP. Numista, который в исходном ТЗ должен
был закрыть остальные страны, в MVP не делаем (нужен персональный API-ключ).

## Критерий готовности MVP

Пользователь регистрируется сам по email (подтверждает адрес по письму) или через Google,
видит общий каталог из 3063 позиций с фотографиями, отмечает свои монеты, заводит личные
позиции для того, чего в каталоге нет, со своими фото, вносит покупки, видит сколько
потратил и сколько стоит коллекция сейчас. Цены украинской части подтягиваются сами раз в
сутки. Аноним без входа видит публичный каталог и карточку монеты — без цен и без
owned-слоя. Импорта из uCoin и экспорта в Excel в MVP нет (решение владельца 2026-09-15,
см. «Откладываем»). Всё это — с телефона через браузер.

Функциональность MVP простым языком, без схемы и эндпоинтов, — `product.md`.
