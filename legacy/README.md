# legacy — артефакты десктопной версии

Всё, что удалось спасти из повреждённого архива предыдущего проекта.

**Это справочный материал, а не код проекта.** Ничего отсюда не импортируется и не
запускается. Смотреть, когда нужно понять, как работало раньше.

## Что здесь

| Файл | Что это |
|---|---|
| `PRODUCT_VISION.md` | Исходное ТЗ, 18 разделов, июль 2026. Продуктовые решения по-прежнему в силе, технические — нет |
| `legacy-schema.sql` | Полный DDL рабочей SQLite-базы, 9 миграций. Справка, не образец: типы под SQLite, пользователей нет. Целевая схема — `docs/02-data-model.md` |
| `ui-strings.json` | Навигация, 226 строк интерфейса, 35 методов API. Извлечено из собранного бандла — исходники интерфейса утрачены |
| `reference-code/` | TypeScript-код десктопной версии. Эталон бизнес-логики |
| `data/` | Рабочая база и фотографии. **В git не попадает** |

## reference-code

| Файл | Строк | Ценность |
|---|---|---|
| `database.ts` | 947 | Главное. Расчёт дашборда, комплектности, финансов, дедупликация импорта, миграции схемы |
| `ucoin-import.ts` | 260 | Скрейпинг uCoin: обход Cloudflare, извлечение из DOM, нормализация URL |
| `pricing.ts` | 200 | API НБУ, парсер UA-Coins, нормализация названий для сопоставления |
| `types.ts` | 185 | Контракт интерфейса и бэкенда — основа для Pydantic-моделей |
| `excel-import.ts` | 97 | Разбор Excel-выгрузки uCoin, раскладка колонок |
| `backup.ts` | 114 | ZIP-бэкап с манифестом и SHA-256. В вебе не нужен, см. `docs/10-infra.md` |
| `main.ts`, `preload.ts` | 178 | Регистрация IPC-методов. Полезно для маппинга на REST |
| `ucoin-login.html` | — | Страница ручного прохождения проверки Cloudflare |

Код в `main.ts`/`database.ts` отстаёт от реальности: в нём 2 миграции, а в рабочей базе 9.
Схеме из `legacy-schema.sql` доверять больше, чем коду.

## data (в .gitignore)

| Файл | Что |
|---|---|

| `media/` | 839 фотографий, 142 МБ |

Личные данные владельца коллекции: покупки, суммы, даты. Репозиторий публичный —
в git этого быть не должно. Проверяй `git status` перед коммитом.

## Что утрачено

Архив был повреждён при переносе: часть файлов обнулена побайтово.

| Утрачено | Последствие |
|---|---|
| `src/` — исходники React-интерфейса | Фронтенд пишем заново. Карта экранов восстановлена в `docs/08-ui-map.md` |

| Живая база и поздние бэкапы | Работаем со снимком от 2026-08-06, потери — несколько часов |
